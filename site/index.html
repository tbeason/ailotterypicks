AI Lottery Picks

Before every Powerball and Mega Millions drawing, each model gets the same prompt with recent results and picks one ticket. The picks are committed to git before the drawing and scored after it.

The honest part: lottery drawings are independent and uniformly random, so no model can beat the Random quick pick baseline except by luck. Any gap on the leaderboard is noise. What's worth reading is how each model reasons about a game that can't be reasoned about.
